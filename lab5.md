### 3. Хід виконання роботи

1. **Моделювання структури даних через масив `$tasks`:**
   Замість окремих змінних створено багатовимірний асоціативний масив, який містить список завдань із ключами `id`, `title`, `priority` та `is_completed`:

```php
$tasks = [
    [
        'id' => 1,
        'title' => 'Виконати лабораторну роботу №5 з PHP',
        'priority' => 'High',
        'is_completed' => false
    ],
    [
        'id' => 2,
        'title' => 'Вивчити роботу з багатовимірними масивами',
        'priority' => 'Medium',
        'is_completed' => true
    ],
    [
        'id' => 3,
        'title' => 'Оформити звіт у файлі lab5.md',
        'priority' => 'High',
        'is_completed' => false
    ],
    [
        'id' => 4,
        'title' => 'Зберегти зміни у Git та відправити на GitHub',
        'priority' => 'Low',
        'is_completed' => true
    ]
];
Динамічний рендеринг списку через цикл foreach:
У блоці <ul> використано цикл foreach з альтернативним синтаксисом для генерації тегів <li> під кожне завдання з масиву:

HTML
<ul>
    <?php foreach ($tasks as$task): ?>
        <li class="<?= $task['is_completed'] ? 'task-done' : 'task-pending' ?>">
            <strong>Завдання:</strong> <?= formatTitle($task['title']) ?>
            <span class="priority priority-<?= $task['priority'] ?>">[Пріоритет: <?= $task['priority'] ?>]</span> — 
            <?php if ($task['is_completed']): ?>
                <span>✔️ Виконано</span>
            <?php else: ?>
                <span>🕒 В процесі</span>
            <?php endif; ?>
        </li>
    <?php endforeach; ?>
</ul>
